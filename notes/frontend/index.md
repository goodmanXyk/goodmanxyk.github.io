# 前端基础

本栏目用于沉淀网页运行原理、HTML、CSS、JavaScript 和浏览器相关知识。

## 建议的笔记结构

每篇笔记可以从一个具体问题出发，并保留以下信息：

1. **问题**：要弄清楚什么？
2. **解释**：关键概念和运行过程是什么？
3. **示例**：能否用最小代码验证？
4. **结论**：有哪些可以记住或复用的要点？

### 示例：浏览器怎样显示一个网页？

浏览器会获取 HTML 文档，再解析文档并加载相关资源。理解这个过程，是继续学习 DOM、CSS 布局与页面性能的起点。

```html
<main>
  <h1>我的第一条前端笔记</h1>
  <p>从能观察到的现象开始，逐步追问背后的机制。</p>
</main>
```
