# 3D无序抓取环境配置

\# 分割无序抓取

<br>
\#\# Installation

<br>
\#\#\# 1\. Baseline

<br>
\- Python 3\.12 or higher
\- PyTorch 2\.7 or higher
\- CUDA\-compatible GPU with CUDA 12\.6 or higher

<br>
\#\#\# 2\. Create New Conda Environment

<br>
    conda create -n sam3 python=3.12
    conda deactivate
    conda activate sam3

<br>
\#\#\# 3\. Install PyTorch

<br>
    pip install torch==2.10.0 torchvision==0.25.0 --index-url https://download.pytorch.org/whl/cu128

<br>
\#\#\# 4\. Install sam3 Requirements

<br>
    git clone https://github.com/facebookresearch/sam3.git   # 或直接下载zip解压
    cd sam3
    pip install -e .

<br>
\#\#\# 5\. Install additional dependencies

<br>
    # For running example notebooks
    pip install -e ".[notebooks]"
    # For development
    pip install -e ".[train,dev]"

<br>
\#\#\# 6\. Optional dependencies for faster inference

<br>
    pip install einops ninja && pip install flash-attn --no-deps --index-url https://download.pytorch.org/whl/cu128
    pip install git+https://github.com/ronghanghu/cc\_torch.git

<br>
\-\-\-

<br>
\#\# Model Installation

<br>
Download the model file \`sam3.pt\` from the following link:

<br>
👉 \[https://modelscope\.cn/models/facebook/sam3/files\]\(https://modelscope\.cn/models/facebook/sam3/files\)

<br>
Use \*\*Ctrl+F\*\* to find \`sam3.pt\` and download it.
